## Token Plan 团队版是什么，适合哪些团队

一句话概括：阿里云百炼面向团队和企业的 AI 模型订阅服务，用 Credits 统一计费，一个订阅覆盖主流 AI 编码和 Agent 工具。

模型池值得单独说。一个订阅能调用 Qwen 3.6–3.8 系列、DeepSeek V4 系列、Kimi K2.5–K2.7、智谱 GLM 5 系列、MiniMax-M2.5 等文本模型，外加图像生成（qwen-image 2.0/3.0、wan2.7-image）、视频生成（happyhorse-1.1 系列）和语音识别、语音合成、实时语音对话模型。工具层面，官方文档列出的可直接接入的工具包括 Claude Code、Cursor、Codex、Qwen Code、OpenCode、Qoder、Cline、OpenClaw、Cherry Studio、Chatbox、通义灵码等十几种。

团队版相对个人版多出来的东西主要是管理能力：管理员控制台可以分配和回收席位、查看成员用量分析；对话数据承诺不用于模型训练；多租户隔离架构保证高峰期不排队。这些对个人用户没什么意义，对要管预算、管合规的团队是刚需。

不适合它的三类情况也说清楚：

- 个人开发者。个人版 Lite 限时 39 元/月就有 11,500 Credits，不用为席位管理多花钱；两版可以同时持有、独立计费，以后团队化再补团队版也行。
- 海外团队。中国站版本只有北京地域，海外用户需要走阿里云国际站的对应版本（新加坡区，美元计价）。
- 想年付锁价的团队。目前订阅周期只有月付和自动续费月付两种，没有年付选项。

## 计费周期按订阅日算，这三条规则最容易被忽略

团队版按“订阅月”计费，从付款那天起算，跟自然月无关。6 月 4 日订阅，有效期就到次月 4 日。由此带来三条对预算有实际影响的规则：

1. **额度一次性发放**。每个订阅月开始时，席位当月额度整批到账，不会按天分摊。
2. **额度不结转**。当月没用完的部分，下个订阅月清零重置。
3. **续费只延时间，不加额度**。续费只是延长订阅周期，不会给当前周期追加额度。

额度用完时，API 调用会被直接拦停，不会自动转成按量付费继续扣钱。这一点对财务是好事——月底不会冒出意外账单——但对赶进度的开发团队就意味着停工。重度团队建议盯住用量分析，提前加购共享额度包（¥5,000/包，625,000 Credits），或者给个别高强度成员升级席位。

## 购买流程：从订阅到成员用上模型只需三步

整个流程在百炼控制台完成，分订阅、发 Key、配工具三步。

### 第一步：完成订阅

用主账号或 RAM 用户登录百炼控制台，确认左上角地域已切换到中国（北京），进入 Token Plan 订阅页，选好席位类型、数量和订阅周期完成支付。

RAM 用户订阅前需要主账号先做两步授权，这是最容易漏掉的前置条件：先在 RAM 控制台给该用户授予 AliyunTokenPlanReadOnlyAccess（只读）或 AliyunTokenPlanFullAccess（管理）系统策略，外加 AliyunBSSReadOnlyAccess（费用只读）策略；再到百炼控制台的账号管理页，给这个 RAM 用户分配「管理员」或「订阅 Plan」角色。两步都做完，RAM 用户才能自行订阅和管理。

### 第二步：分配席位，生成成员 API Key

在控制台的成员管理页给成员分配席位，然后为成员生成 API Key。两个细节要注意：必须先分配席位才能生成 Key；Key 以 sk-sp- 开头，只在生成或重置时完整显示一次，之后控制台只显示掩码（sk-sp-****），生成时务必当场复制保存。

### 第三步：把 API Key 和 Base URL 填进 AI 工具

Token Plan 提供两个官方接入地址，按你的工具支持的协议选一个：

| 协议 | Base URL |
| --- | --- |
| OpenAI 兼容 | https://token-plan.cn-beijing.maas.aliyuncs.com/compatible-mode/v1 |
| Anthropic 兼容 | https://token-plan.cn-beijing.maas.aliyuncs.com/apps/anthropic |

### Key 配错会真扣钱

这是整个流程里代价最高的坑。Token Plan、Coding Plan、按量付费三套体系的 API Key 和 Base URL 完全隔离，必须配对使用。如果买了 Token Plan，却配了按量付费的 sk- 开头 Key 或其他计费模式的 Base URL，请求会被路由到按量付费通道直接扣现金，或者返回 401/403 鉴权错误。给成员发 Key 时，把 sk-sp- 前缀和对应的 token-plan 域名一起写进使用说明，能省掉不少售后问题。

## 怎么让额度更耐用：夜间五折与几个计费细节

团队版目前有一个明确的省钱窗口：每天 22:00 到次日 08:00（UTC+8），deepseek-v4-pro-0813、deepseek-v4-flash-0731、deepseek-v4.1-flash 三款模型的 Credits 消耗打五折。夜间跑批量任务、定时任务的团队，把这三款模型的任务调度到这个时段，额度消耗直接减半。促销活动阿里云保留调整权利，实际折扣以控制台最新页面为准。

另外两件事会影响额度消耗速度，做预算时算进去：

- **内置模型工具按 Credits 计费**。联网搜索（web_search）、以图搜图（image_search）、网页抓取（web_extractor）、代码解释器（code_interpreter）在模型调用中自动触发，按系数扣 Credits。Agent 重度使用时，这部分消耗不小。
- **多模态生成模型走单独 API**。wan2.7-image、happyhorse-1.1-t2v 这类图像、视频生成模型需要通过工具的 Skill 或扩展机制接入，主对话里找不到入口不代表不支持。

## 常见问题

**个人版和团队版能同时买吗？**
能。同一个阿里云账号可以同时持有两版订阅，独立计费，互不影响。

**额度用完了怎么办？**
API 调用会被拦停，不会自动转按量扣费。可以加购共享额度包（¥5,000/包，625,000 Credits），或等下个订阅月额度重置。当月剩余额度不结转，囤着不用没有意义。

**原来的 Coding Plan 能升级或转成 Token Plan 吗？**
不能。两个是独立产品，不支持迁移和升级。Coding Plan Lite 已于 2026 年 3 月 20 日停止新购，4 月 13 日起停止续费和升级；还在用 Coding Plan 的团队要换 Token Plan，只能新订。

**一个 API Key 能给全组人用吗？**
不能。一个席位绑定一名成员和一个 API Key，官方明确不支持共享。需要覆盖更多人就增加席位数。

**RAM 子账号怎么开通？**
需要主账号先在 RAM 控制台授予 Token Plan 相关策略和费用只读策略，再在百炼控制台给该用户分配管理员或订阅角色，之后 RAM 用户才能自行订阅，详见上文购买流程第一步。

**海外团队能买吗？**
中国站版本仅在北京地域提供。海外团队可用阿里云国际站的对应版本（新加坡区，美元计价）：标准席位限时 $20/席/月，Pro 席位 $75，Max 席位 $200，额度标准与国内版一致。
